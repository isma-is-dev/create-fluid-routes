# Create: Fluid Routes

**See your whole pipe network on Xaero's World Map.**

Pipes, pumps, tanks and spouts as one continuous blue line, routed from Create's real pipe
openings.

## Features

- **Pipe lines** from `FluidPipeBlock.isOpenAt`: casings, brackets, tees and capped ends are
  accurate.
- **Node markers**: cyan pumps, blue tanks, violet spouts, grey-blue isolated pipes.
- **On-map toggle** with a live pump counter.
- **No blocks, no items, no worldgen** — add and remove freely.

## Performance

Nothing is collected while no map is open; chunk load/unload indexing; textures rebuild only
when the pipe graph changes; chunked, config-capped packets.

## Requirements

- Minecraft 1.21.1, NeoForge 21.1.x
- Create 6.0.10+ (required)
- Xaero's World Map 1.40.x (optional — the mod does nothing without it)
